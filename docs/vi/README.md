# Tài liệu GeoEyes bằng tiếng Việt

Bản tiếng Việt của tài liệu trong `docs/en/`, cùng cấu trúc thư mục ([bản tiếng Anh](../en/README.md)). Bản gốc tiếng Anh là bản chuẩn (ADR-015,
ADR-027); đầu mỗi tệp ghi rõ bản gốc và ngày dịch. Thuật ngữ: [GLOSSARY.md](GLOSSARY.md).
