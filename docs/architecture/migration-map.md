# GeoEyes — Migration map (old file → new location)

> Every current file/directory has exactly one row: where it goes, or whether it is deleted. Target architecture: [`ARCHITECTURE.md`](ARCHITECTURE.md).
> Target paths are relative to `src/geoeyes/` unless they start with `apps/`, `third_party/`, `tests/`, `docs/`, `scripts/`, or `$WS` (= `$GEOEYES_WORKSPACE`).
>
> **Action**: `move` (moved almost unchanged) · `split` (split into several modules) · `merge` (several sources merged into one) · `port` (rewritten to the new contract, keeping the algorithm) · `replace` (replaced by a new mechanism) · `delete` (deleted) · `legacy` (only kept in `io/legacy` to read legacy data).
>
> The **Phase** column = the phase in TODO.md that will handle it.
