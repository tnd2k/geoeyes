## Open work (2026-10-25)

The refactor itself is done: native processing chain for Sentinel-1, COSMO-SkyMed and Capella, products, reports,
catalog, web app; legacy code removed; `git init`. What remains, by priority:

1. **Science / processing**: investigate the constant-phase interferogram of the CSK golden AOI; SBAS method; 3D
   decomposition (ascending + descending); quality metrics into the manifest; ISO 19139 metadata.
2. **Sensors**: ALOS-PALSAR (reader, preset, split-spectrum ionosphere, golden); TSX when data arrive (golden case
   `pipeline`, both stack geometries).
3. **Operations**: storage tiers and retention, optional object storage; `geoeyes migrate` command; a new
   `environment.yml` (the current `insar` env has broken GDAL Python bindings and stale packages).
4. **Project owner**: `LICENSE`; the two open questions under Phase 0.

The sections below are the historical log, phase by phase.

## Principles (unchanged)

- No git until the repo is clean (project owner's decision). Before each large batch of changes: **zip backup of the code**.
- Every refactor step must keep numerical results unchanged (compared with the golden output), unless the step deliberately changes the algorithm.
- Never change structure and logic in the same step.
- Design first, then code.
